# Dora Box Manual

## Features

- Data encryption
- Data decryption
- File encryption
- File decryption
- Time lock
- Password input available during encryption and decryption
- Cross-device data synchronization
- Specific UI for input and preview of data in different formats
- Stablecoin payment
- Store data locally on mobile phones
- Back up mobile local data to cloud archives
- Archive version chain
- Soft deletion of archives
- Archive recovery
- Multiple redundant archive backups
- ERC-20 address indexed archives
