# Dora Cloud Manual

### Introduction

Dora Cloud is designed for redundant file backup. Files can be backed up to multiple locations, 
including Dora Cloud sites, Alibaba OSS, and decentralized on-chain cloud (under development). 
Users have direct access to the URL of each node without going through the platform. In addition, 
data from Dora Box is also stored in Dora Cloud, sharing the storage space. Storage space can be 
purchased with stablecoins for capacity expansion, and users may also subscribe to VIP to obtain 
time-limited storage capacity. Files stored in Dora Cloud are indexed by ERC-20 addresses.
